# NFL Home-Field Advantage

This project investigates whether home-field advantage in the NFL has decreased since the COVID-19 pandemic. It compares home-team win percentages before and after the pandemic and examines whether the observed change is statistically significant.

## Research Question

Has NFL home-field advantage decreased since the COVID-19 pandemic?

## Hypotheses

- **Null hypothesis (H₀):** Home-field advantage remained the same before and after the pandemic.
- **Alternative hypothesis (H₁):** Home-field advantage decreased after the pandemic.

## Analysis

The project examines home-team win percentage by season and compares two periods:

- **Pre-pandemic:** 2014–2019
- **Post-pandemic:** 2021 onward

The 2020 season is excluded from this period comparison. The analysis also evaluates whether the difference between the two periods is statistically significant.
